# GX Works 가능성 확인 (PoC) — 이슈 #44

GX Works가 설치된 Windows PC에서 직접 확인하고 채워요. **확인하지 않은 칸은 "미확인"으로 두고, 추측으로 적지 않아요.** 라이선스 키와 비밀값은 적지 않아요.

상태: **미실시** (작성 PC에는 GX Works와 FFmpeg가 없어 확인하지 못했어요.)

## 1. 환경

| 항목 | 값 |
|---|---|
| 확인한 사람 / 날짜 | 미확인 |
| Windows 버전 | 미확인 |
| GX Works 제품·버전 (GX Works3 / GX Works2 / GX Developer) | 미확인 |
| CPU 모델 | 미확인 |
| 시뮬레이터(GX Simulator) 사용 가능 여부 | 미확인 |
| Python / pywinauto 버전 | 미확인 |
| FFmpeg 버전 | 미확인 |

## 2. 가져오기/내보내기 형식 확인

기준 회로: 자기유지 회로 1개 (시작 버튼, 정지 버튼, 출력 코일).

- [ ] GX Works에서 회로를 직접 만들었어요.
- [ ] 프로그램 내보내기에서 지원하는 형식을 확인했어요: 미확인 (예: CSV, 텍스트)
- [ ] 내보낸 파일의 구조(열, 명령어 표기, 디바이스 이름)를 기록했어요.

| 형식 | 내보내기 | 가져오기 | 비고 |
|---|---|---|---|
| 미확인 | 미확인 | 미확인 | |

## 3. 가져오기 → 컴파일

- [ ] 같은 내용의 파일을 새 프로젝트에 가져왔어요.
- [ ] 저장하고 컴파일했어요.
- 결과: 미확인
- 실패 메시지: 없음 / 미확인

## 4. UI 자동화 (pywinauto)

- [ ] 프로젝트 생성, 가져오기, 저장, 컴파일을 자동으로 할 수 있는지 확인했어요.
- 결과: 미확인
- 막힌 지점: 미확인

## 5. 시뮬레이터와 녹화

- [ ] GX Simulator를 띄우고 디바이스 값을 바꿀 수 있어요.
- [ ] 출력 변화를 확인했어요.
- [ ] FFmpeg(`gdigrab`)로 시뮬레이터 창을 녹화하고 재생을 확인했어요.
- 결과: 미확인

## 6. 결정

- 선택한 방식: 미정 (권장: 가져오기 + UI 자동화)
- 근거: 미정
- 불가능한 부분과 제한: 미정
- 대안: 미정

호환성 상태는 `verified` / `unverified` / `unsupported` / `failed` 중에서만 표기해요 (TRD 9장).

- 현재 상태: `unverified`

## 7. 안전 고지

생성된 파일과 영상은 설계 초안이에요. 실제 설비에 적용하기 전에 자격을 갖춘 사람의 검토가 필요하고, 이 도구는 PLC에 쓰거나 전송하지 않아요.
