# 사용자 가이드

> **꼭 읽어 주세요.** 이 프로그램이 만든 회로는 **초안**이에요. 모의 실행을 통과해도 실제 설비의 안전을 보장하지 않아요. **실제 설비에 적용하기 전에 전문가가 반드시 확인해야 해요.**

MELSEC **Q시리즈 래더** 회로를 만들어 주는 프로그램이에요. 조건을 글로 적으면 AI가 분석·설계하고, 서버가 검증해서 결과를 보여 줘요. 현재는 Q시리즈 래더·자동 모드만 지원해요.

## 전체 순서

화면 위쪽에 6단계가 있어요. 첫 화면을 제외한 모든 화면에는 왼쪽 아래에 **처음으로** 버튼이 있어요.

| 단계 | 하는 일 |
|---|---|
| 1. 기본 설정 | PLC 정보와 입출력(I/O) 목록을 적어요 |
| 2. 동작 조건 | 회로가 해야 할 일을 문장으로 적어요 |
| 3. 설계 요청 | AI 분석·설계를 실행해요 |
| 4. 검증 결과 | 조건을 하나씩 확인한 결과를 봐요 |
| 5. 모의 실행 | 웹에서 회로를 직접 눌러 보며 시험해요 |
| 6. 파일 받기 | GX Works2에서 열 수 있는 파일을 받아요 |

## 1. 기본 설정

- **시리즈·CPU·언어·GX Works 버전:** 서로 맞는 조합만 선택돼요. 맞지 않으면 안내가 나와요.
- **입출력 목록:** 사용할 X(입력)·Y(출력) 주소, 이름, 종류를 적어요. 주소는 CPU의 점수 안에서만 쓸 수 있어요.
- **푸시버튼 종류:** 꼭 실제 버튼과 같게 골라요.
  - `푸시버튼 NO (a접점)`: 누르면 연결되는 버튼 (보통 시작 버튼)
  - `푸시버튼 NC (b접점)`: 누르면 끊기는 버튼 (보통 정지·비상정지 버튼)
  - 이름이 "정지"여도 종류로만 판단해요. 종류와 회로의 접점이 다르면 서버가 거부해요.
- **비상정지:** 사용하면 모든 입력부 회로에 b접점으로 직렬 연결돼요.
- **안전 고지 동의:** 필수예요.

## 2. 동작 조건

- 한 줄에 조건 하나, **구체적으로** 적어요. 숫자(시간·개수)를 넣어요.
  - 좋은 예: `시작 버튼을 누르면 모터1이 켜지고 계속 유지돼요.`
  - 좋은 예: `모터1이 켜지고 3초 뒤에 모터2가 켜져요.`
  - 부족한 예: `잠시 뒤에 켜져요.` (몇 초인지 몰라서 AI가 되물어요)
- **필수 조건**은 하나라도 틀리면 실패예요. 선택 조건은 경고만 해요. 필수 조건이 1개 이상 있어야 해요.
- 안전 관련 조건(비상정지 때 동작, 동시에 켜지면 안 되는 출력)을 빠뜨리지 마세요.
- 양식 예시는 화면의 템플릿 기능으로 불러올 수 있어요.

## 3. 설계 요청

버튼을 누르면 분석 → 설계 → 검증(→ 수정) 순서로 진행돼요. 단계마다 걸린 시간이 보여요.

- **추가 질문이 나오면:** 애매한 조건이 있다는 뜻이에요. 답을 적고 **답변 반영해 다시 분석**을 눌러요.
- **실패·사람 확인 필요가 나오면:** 화면의 이유를 읽고 조건을 고쳐서 다시 시도해요.
- 브라우저를 새로고침하면 같은 탭에서는 마지막 프로젝트와 결과가 다시 보여요.

## 4. 검증 결과 읽는 법

서버가 회로를 모의 실행해서 조건마다 **통과/실패**를 보여 줘요. AI가 아니라 코드가 판단해요.

- **필수 조건 실패:** 전체가 실패예요. 어느 렁, 몇 초에, 기대값과 실제값이 뭔지 알려 줘요.
- **선택 조건·경고:** 참고용이에요.
- **자동 안전 탐색:** 시험과 별개로 입력을 바꿔 보며 아무것도 안 눌렀는데 켜지는지, 비상정지 중에 켜져 있는지, 한 번도 안 켜지는 출력이 있는지 봐요.
- **수정 이력:** 검증에서 실패하면 AI가 고치고, 서버가 모든 조건을 다시 확인해요. 고친 내용과 거절된 내용이 남아요.
- **검증 기준** 버튼에서 기준 설명을 볼 수 있어요.

## 5. 모의 실행

웹에서 회로를 시험해 볼 수 있어요. 버튼을 눌러 입력을 켜고 끄며 출력이 맞게 나오는지 직접 확인해요. 실제 PLC와 같다는 뜻은 아니에요.

## 6. 파일 받기

- **GX Works2 파일 받기 (.csv):** 누르면 `circuit-gxworks2.csv`가 저장돼요.
- **GX Works2에서 여는 방법 보기:** 화면 안내(7장)를 순서대로 따라 해요.
  1. 프로젝트를 만들 때 **시리즈·CPU를 맞춰** 선택해요.
  2. `Edit` → `Read from CSV File`에서 받은 파일을 열어요.
  3. GX Simulator2로 시뮬레이션을 시작해요.
  4. 시뮬레이션 화면에서 `Shift + Enter`로 디바이스를 ON/OFF 할 수 있어요.
- **명령어(IL) 보기:** 회로를 명령어로 보고 싶을 때 펼쳐요.
- 푸시버튼은 누르면 ON이에요. 그래서 GX Simulator2에서 아무것도 안 눌렀을 때(OFF)부터 그대로 시험할 수 있어요.

> CSV는 Q03UD, Q03UDV에서 열리는 것을 확인했어요. 파일 안의 CPU 이름이 달라도 열렸어요. 다른 CPU는 직접 확인하지 못했어요.

## 전문가 검토 절차

실제 설비에 적용하기 전에 아래를 **사람이** 확인해요.

1. GX Works2에서 파일을 열어 회로를 눈으로 읽어 봐요. 조건과 맞는지 확인해요.
2. GX Simulator2로 정상 동작, 정지, **비상정지**를 모두 시험해요.
3. 설비 담당 전문가가 안전 회로(비상정지·인터록)와 CPU 용량(입출력 점수, 내부 릴레이·타이머 개수)을 확인해요.
4. 실제 설비에서는 안전한 조건(무부하, 저속 등)으로 먼저 시험해요.
5. 검토한 사람과 날짜를 기록해요.

## 자주 묻는 질문

- **회로가 거부돼요 (KIND_MISMATCH):** 푸시버튼 종류(a/b접점)와 회로의 접점이 달라요. 입출력 목록의 종류를 확인하세요.
- **IO_SPLIT 오류:** 출력(Y)은 내부 릴레이(M)의 접점으로만 구동해야 해요. AI가 다시 설계하면 보통 해결돼요.
- **GX Works2에서 파일이 안 열려요:** 프로젝트가 Q시리즈 래더(Q mode)인지 확인하세요.
- **화면이 이상해요:** 새로고침하거나 **처음으로**를 눌러 다시 시작해 보세요.
